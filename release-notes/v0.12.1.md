## Highlights

- The website’s Bootstrap section now offers shorter commands for downloading AXE with `curl` or `wget`, pasting Python, Node.js, Perl, or Shell scripts, and writing a Native ELF loader. ([939937ad977cd5ab3b16b60c989b993a46c0dbf1])
- Native loader bytes are embedded in `bootstrap.json`, allowing the website to generate a self-contained paste command instead of requiring a separate loader download. ([d5aa376b3dbcf244361928b5514d4fa4785152eb])
- Native x86_64 and aarch64 loaders are smaller: the ELF layout change reduces them from about 8.7 KiB to 4.8 KiB and 4.9 KiB respectively. ([1ff880f2d6379e8b5642e849c6f9c0e1c50f4d1d])

## Changes

- Bootstrap commands are grouped into download, pasted-script, and Native ELF modes. Python and Node.js payloads use zlib-compressed hex when supported; Perl uses hex; Native loaders can be written with POSIX `printf` escapes or `base64`. ([939937ad977cd5ab3b16b60c989b993a46c0dbf1])
- The website now displays the generated command length and keeps long commands in a scrollable block. ([939937ad977cd5ab3b16b60c989b993a46c0dbf1])
- Local website builds now copy `bootstrap.json` from the newest staged release under `dist/releases`, and omit stale bootstrap data when no staged release is available. ([21a13dba59288a3a93729fdd588e9a7192b411ba])

## Fixes

- Local website builds no longer depend on an unrelated or stale copy of bootstrap data: the build selects a versioned staged release and removes the target file when none exists. ([21a13dba59288a3a93729fdd588e9a7192b411ba])
