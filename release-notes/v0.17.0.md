## Highlights

- SSH sessions now support per-session agent forwarding. ([b646cb4](https://github.com/buglloc/axe/commit/b646cb4dc344e0862fe6f2d9a810ebac035ed6b1))
- SFTP adds OpenSSH extensions for atomic replacement rename, hard links, file synchronization, filesystem statistics, and transfer limits. ([b646cb4](https://github.com/buglloc/axe/commit/b646cb4dc344e0862fe6f2d9a810ebac035ed6b1))

## Changes

- `sshd --accept-env` controls accepted client environment variables with `*` and `?` patterns; the default is `LANG,LC_*`. Variables remain isolated between sessions, while session identity and Store policy remain server-controlled. ([b646cb4](https://github.com/buglloc/axe/commit/b646cb4dc344e0862fe6f2d9a810ebac035ed6b1))
- SSH PTYs apply requested terminal modes. SSH signals reach the session’s process group, signal termination is reported to clients, and session cleanup stops remaining processes in that group. ([b646cb4](https://github.com/buglloc/axe/commit/b646cb4dc344e0862fe6f2d9a810ebac035ed6b1))

## Fixes

- Relay registrations cap active tunnels at 128. Excess traffic waits for capacity instead of tearing down the registration, and disconnects close session-owned tunnels. ([016848c](https://github.com/buglloc/axe/commit/016848c78d666015e6392a1bff56c80f18a356f1))
- Relay registration deadlines now include port allocation. Short-lived registrations increase reconnect backoff instead of resetting it. ([016848c](https://github.com/buglloc/axe/commit/016848c78d666015e6392a1bff56c80f18a356f1))
- Darwin builds deduplicate framework linker arguments, preventing duplicate CoreFoundation library loads. ([bb48033](https://github.com/buglloc/axe/commit/bb480337c211c347abbfab8998ab5e7e5829e4c1))
- `printf` compiler probes run in Cargo’s output directory, preventing Darwin cross-build probes from leaving `a.o` in the vendored source tree. ([729a36b](https://github.com/buglloc/axe/commit/729a36bfdd5198405c61a33ac84e62c3aa28a8cb))
