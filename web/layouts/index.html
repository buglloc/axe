Certificate identity

OpenSSH user certificates authorize logins. The certificate principal matches the login and its configured allowlist.

02

QUIC authentication

The target and relay authenticate each other with separate certificates.

03

Outbound registration

The target connects to the relay, which assigns a public TCP port for SSH access.
